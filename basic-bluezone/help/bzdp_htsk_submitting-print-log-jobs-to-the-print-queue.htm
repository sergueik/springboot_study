Submitting print log jobs to the print queue

Print Log jobs can be manually submitted to the Print Queue for printing.

  1. Highlight the desired job(s) in the Print Log window.
  2. From the menu bar, click Action → Select Add Job(s) to Queue or click the Add Job(s) to Queue icon on the toolbar.
Another method for submitting Print Log jobs to the Print Queue is to drag and drop the desired job(s) into the Print Queue window.
