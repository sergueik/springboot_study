Configuring the history pad

The History Pad window is a type of power pad that provides a visual representation of each screen that is stored in the screen history buffer. Like a power pad, the History Pad window can be viewed as a separate window or docked to the display.

The power pad feature must be enabled for the History Pad window to display. To enable power pads:

  1. Click View → Properties.
  2. Select the Power Pads tab.
  3. Select the Show Power Pads check box.
  4. If you want to dock the History Pad window, select the Enable Docking check box.
  5. Click OK.
