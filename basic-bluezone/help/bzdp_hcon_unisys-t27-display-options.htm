Unisys T27 display options

  • Display Options dialog
    The Display Options dialog allows you to configure the following settings:
  • Keyboard Options dialog
    The Keyboard Options dialog is used to map BlueZone T27 program functions to key sequences on the keyboard.
  • Mouse Options dialog
    The Mouse Options dialog is used to configure the special mouse features which control the behavior of the mouse when using BlueZone T27.
  • Sounds Options dialog
    The Sounds Options dialog is used to configure the BlueZone special sound features which control the behavior of host and application sounds when using BlueZone.
  • API Properties dialog
    The API Properties dialog is used to configure BlueZone to work with external programs. To launch the API Properties dialog, go to the BlueZone menu bar, and click Options → API.
