Returning to the active screen

There are four methods to cancel the screen history view and return to the active screen:

  • Press any key.

    Note: If the History Pad window is open, the focus must be on the display.

  • Click View → Screen History → Cancel.

  • From the toolbar or the History Pad window, click the History Cancel toolbar button.

    Note: You must manually add the screen history buttons to the toolbar.

  • In the History Pad window, click Active Screen (the last screen in the window).
