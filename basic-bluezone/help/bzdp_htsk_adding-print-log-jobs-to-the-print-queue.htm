Adding print log jobs to the print queue

Print Jobs residing in the Print Log can be added to the Print Queue for printing. To add a Print Log job to the Print Queue:

  1. In the Print Log window, highlight the desired Print Job(s).
  2. Click Action → Add Jobs to Queue from the BlueZone menu bar or click the Add Jobs to Queue icon on the BlueZone toolbar.
Or, you can also:
  1. In the Print Log window, highlight the desired Print Job(s).
  2. Drag and drop the print job icon into the Print Queue window.
Note: Print Log Jobs added to the Print Queue are not resubmitted to the Print Log when the job has completed printing.
