Running transfer lists

  1. Start an iSeries Display session.
  2. Click Transfer → Send/Receive.
    If the transfer list was saved with the display session, it is already displayed in the Transfer List pane.
  3. If the transfer list was not saved with the display session or you want to open a different transfer list, click List → Open.
  4. Select a transfer list (.adl) and click Open.
  5. Click List → Run.
    The transfer entries are either sent to the host or received from the host.
