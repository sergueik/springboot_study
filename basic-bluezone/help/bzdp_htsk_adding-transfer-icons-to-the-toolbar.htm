Adding the transfer icon to the toolbar

You can add the BlueZone Host File Transfer icon to the BlueZone toolbar.

  1. Start a BlueZone iSeries Display session.
  2. From the BlueZone menu bar, click View → Properties.
  3. Select the Show Menu Buttons check box, if it is not already selected.
  4. Next to Show Menu Buttons, click Customize.
  5. In the Available toolbar buttons pane, highlight the Send/Receive icon.
  6. Click Add.
  7. Drag the Send/Receive icon to the necessary location in the Current toolbar buttons lists.
  8. Click Close to close the Customize Toolbar window.
  9. Click OK to close the View Properties window.
Note: You must save your BlueZone Display session for the toolbar change to be permanent.
