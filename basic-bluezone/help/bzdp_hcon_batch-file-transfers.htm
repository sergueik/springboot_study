Batch file transfers

You have the option of creating batch file transfers. Batch file transfers are two or more individual file transfers that you configure, which can be launched by clicking one button.

  • Configuring batch file transfers
  • Saving batch file transfer configurations to a file
    You can save, or export, batch file transfers for the purposes of managing multiple batches or you can save them so you can share them with other BlueZone users.
  • Importing batch file transfer configuration files
    You can import Batch File Transfers that have been previously saved.
