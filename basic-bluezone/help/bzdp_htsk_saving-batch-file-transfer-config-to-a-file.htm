Saving batch file transfer configurations to a file

You can save, or export, batch file transfers for the purposes of managing multiple batches or you can save them so you can share them with other BlueZone users.

  1. Click Transfer → Configure from the BlueZone menu bar.
  2. Click the Batch Transfers tab.
    The Batch Transfers dialog opens.
  3. Click the Export icon located on the Host File Transfer toolbar.
    A standard Windows File Save dialog displays.
  4. Type a name for this configuration and click Save.
    BlueZone automatically assigns the correct file extension (.vdf) to this file. The file is stored in the BlueZone\Config folder.
