Connections tab

MATIP Connections
  • Connection List: Contains the names of the defined host connections. A total of 64 connections can be specified.
    • New: Click to create new host sessions.
    • Edit: Click to edit an existing host connection.
      Note: The Edit Connection window is essentially the same as the Define New Connection window. Use the Define New Connection window as a reference for the Edit Connection window . Refer to Creating BlueZone ALC Display connections for more information.
    • Remove: Click to remove an existing host connection. The highlighted connection is removed from the list.

    • Sort: Click to sort the Connection List in alphabetical order.

  • Use Connection Name as Session Description: If selected, the name that you gave to the active connection is displayed in the BlueZone title bar immediately after the session number. This feature is useful if you have multiple hosts defined, you are not using the Connections list, and you want to know the name of the current connection.
