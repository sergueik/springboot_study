Configure host connections

The T27 Host Connections dialog is used to control the overall operation of the configuration process and to configure virtual destinations.

Configuring a host connection requires the following steps:
  • Launching the T27 Host Connections dialog
  • Editing the default virtual destination
  • Selecting a connection point
  • Launching the T27 Terminal Configuration Settings window
  • Editing the default virtual destination
    You must edit the default virtual destination to include your host information.
  • Selecting a connection point
    After the virtual destination has been configured, you must select a connection point.
