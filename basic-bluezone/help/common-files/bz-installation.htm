BlueZone installation

BlueZone is distributed through a downloaded CD image.

The following steps are a high-level overview of the standard installation process:
  1. Review and ensure that your system meets the installation requirements.
  2. Install, upgrade, or modify BlueZone.
  3. Register BlueZone (first time installations only).
