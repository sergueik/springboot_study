Installing BlueZone 7.1

Prerequisites

  • Ensure that your environment meets the installation requirements. Refer to System requirements for more information.

    Note: BlueZone Unisys UTS Display Emulator and BlueZone Unisys T27 Display Emulator are only available in a 32-bit version. All other BlueZone emulation clients are available in a 32-bit or 64-bit version. If you have a 64-bit operating system, you can install either the 32-bit or 64-bit version; if you have a 32-bit operating system, you can only install the 32-bit version.

  • Locate the license file (LIC) that was sent to your by Rocket Software. You will need to access this file during the installation process.

    If you do not have a LIC, or if you are evaluating BlueZone, you can skip the Choose Activation File window, and install the LIC at another time.

Procedure

  1. Download the BlueZone CD image.
  2. Open the BlueZone Desktop folder.
  3. Open either the win32 folder (for 32-bit installation) or the x64 folder (for 64-bit installation).
  4. Double-click the setup.exe file.
  5. The wizard guides you through the installation process. It is recommended to use the default settings.
  6. When the installation is complete, click Finish.
