Configure the screen printer

You can configure the following:

  • Printer device selection and setup
  • Pass-through printing
  • Screen printer device assignments
  • Adding printers
    The Printer Device Selection and Setup dialog contains controls to equate an installed printer on the PC to a local printer name, use of a local print object, set special UTS print characteristics such as pass-through printing or assign Windows print settings.
  • Selecting configured printers
    Once printers are added in the UTS Printer Manager, you can assign printers to one of three screen DIDs.
