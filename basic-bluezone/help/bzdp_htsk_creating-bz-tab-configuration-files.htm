Creating BlueZone Tab profiles

To use an existing BlueZone session profile or an existing BlueZone Tab profile, select either BlueZone Profiles (*.z??) or BlueZone Tab Profiles (*.bzt) from the drop-down menu in the lower right corner of the Select or Create a Tab Profile window, then select the profile. If you select a BlueZone session profile, a new BlueZone Tab profile will be created when saving on exit. To create a new BlueZone Tab profile, complete the following steps:
  1. Click Start → All Programs → BlueZone 7.1 → BlueZone Tab.
  2. In the File Name field, type a name for the BlueZone tab profile, and click Open.
  3. In the Select or Create a Tab Profile window, click Yes.
