View menu

  • View properties
    The View Properties window is used to configure the toolbar, power pads, status bar, and the color scheme.
  • Scratch pad
    The scratch pad is a text window that you can type, paste, and copy text in a BlueZone session. The text can be formatted, cleared, saved as a text file, or printed. If the scratch pad is closed with text still in the window, the text remains in the window when you reopen the scratch pad.
  • Auto-Size features
    BlueZone features include three auto-size functions: Auto-Size Smaller, Auto-Size Larger, and Full Screen. These features can be accessed by selecting View from the from the BlueZone menu bar or by clicking the corresponding icon on the toolbar.
