BlueZone Tab

The BlueZone Tab component embeds multiple BlueZone Display, Printer, and FTP sessions into a single window. BlueZone Tab is installed with the BlueZone Terminal Emulation Suite.

The BlueZone Tab window has the following features:
  • Contains a tab for each session, up to 1024 tabs
  • Allows users to view the sessions at the same time, using the tile view
  • Uses a single program in the Windows taskbar
  • Adjusts the dynamic menu bar depending on the session type of the active tab
