Scrollback tab

The scrollback buffer is a configurable feature. You can choose to turn it on or off and also, you can set the size of the scrollback buffer.

Scrollback Buffer Options
  • Enable Scrollback Buffer: If selected, BlueZone VT creates a scrollback buffer based on the size configured below.
  • Number of lines in scrollback buffer: Set the number of lines that you want in your scrollback buffer here. Valid ranges are from 50 to 99999 lines.
  • Memory Check: Click to check to see if you have enough memory resources for the size scrollback buffer you have configured. If you do not have enough memory, try reducing the size of the scrollback buffer.
  • Add Scrolling Region Data: If selected, BlueZone VT adds the lines of data in the scrolling region to the scrollback buffer as the lines are scrolled off the active screen. The scrolling region is controlled by the host application.
Note: The scrollback buffer is not configurable when BlueZone VT is connected to a host.
Scrolling Options
  • Enable Smooth Scrolling: When disabled, the scrolling is done as fast as possible. When enabled, the scrolling is delayed to look smoother.
  • Erase Scrolling Data On Connect: When enabled, the scrolling data from the previous session is cleared when reconnecting to the host. When disabled, the scrolling data from the previous session remains on the screen. Enabled by default.
