Changing the tab colors

  1. In the BlueZone Tab toolbar, click the Settings icon.
    By default, the BlueZone Tab toolbar is located in the bottom right corner of the window.
  2. On the Colors tab, select the Use Custom Colors check box.
  3. From the Color # menu, select the tab that you want to configure.
    The Highlight option configures the active tab.
  4. To change the background color of the tab, select the Background radio button, and then click Change.
  5. To change the text color in the tab, select the Foreground radio buttons, and then click Change.
  6. In the Tab Color Pattern field, type the color pattern of the tabs. You can type the numbers 1-9 in any order.
    For example, if you type 12, the tabs repeat the colors 1 and 2. The Sample pane shows the appearance of the selected options.
  7. To add a gradient variance to the tabs, select the Gradient Brush check box.
  8. Click OK.
