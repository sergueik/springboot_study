Configuring APVUFILE (IND$FILE for DBCS) with DBCS support

Before you can transfer DBCS files, you must properly configure DBCS and translation options.

Prerequisites

Before you can configure IND$FILE for DBCS support, complete the following steps:

  • Ensure that the Windows and BlueZone configuration requirements for DBCS support are met.

  • Disable spell checking. If spell checking is enabled, you cannot process DBCS files.

Procedure

  1. From the Mainframe Display session, click Transfer → Configure.
    The Host File Transfer window opens.
  2. Click the DBCS tab.
  3. Select the Enable DBCS Processing check box.
  4. Select the PC Code Page.

    BlueZone reads the header on the file and automatically selects the code page for uploads. If the file does not have a header, ANSI is the default code page.

  5. Select the appropriate File Options:
    • SO - When receiving a text file, SO and SI (hex '0E' and '0F') characters will be converted to RS and US (hex '1E' and '1F')
    • NOSO - When sending a text file, SO and SI (hex '0E' and '0F') characters will NOT be inserted before and after DBCS data, and RS and US (hex '1E' and '1F') will NOT be converted to SO and SI (hex '0E' and '0F')
    • USER - When receiving a text file with the SO option, SO and SI (hex '0E' and '0F') characters will NOT be converted to RS and US (hex '1E' and '1F')
  6. Click OK
