Adding a printer queue

The BlueZone TCP/IP Print Server has the ability to support multiple print queues.

  1. Right-click in the Printer Queues window.
  2. Select Add Printer Queue from the pop-up menu.
    A standard Windows Printer Selection dialog opens.
  3. Select the desired printer from the drop-down list box.
  4. Click OK.
    The Print Setup for Queue dialog opens.
  5. Type a name in the Queue Name field.
  6. Make any desired changes and click OK.
