MATIP Properties

In the MATIP Properties window, you can configure the ____ settings for the MATIP connections.

  • Connections tab
  • Security tab
    The BlueZone ALC emulator supports SSL v3, TLS v1, or SSH v2. BlueZone ALC can be preconfigured for distribution with encryption configured and enabled eliminating the need for any end user intervention in the installation or configuration process.
  • Certificate tab
  • Keep Alive tab
  • Trace tab
  • Firewall tab
    The Firewall tab allows the configuration of firewall and proxy server sign on systems.
  • Security Server tab
    The Security Server tab is used to configure BlueZone to use the BlueZone Security Server as a Proxy Server to multiple hosts. This feature enables you to support connecting to multiple back end hosts through a single port in the BlueZone Security Server while using HTTPS tunneling in BlueZone.
