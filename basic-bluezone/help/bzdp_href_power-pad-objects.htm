Adding power pad objects

You can add four types of power pad objects: buttons, group boxes, text, and pictures.

  1. From the Power Pad Editor Control menu, select the object type that you want to add.

  2. In the power pad canvas, click and drag until the object is the size that you want. You can edit the size of the object at any time.

  3. Double-click the object and configure the properties.

  4. Add and configure as many objects as needed. You can add up to 128 objects per power pad.

  5. Save the power pad file.
