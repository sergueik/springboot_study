SNA Gateway configuration

BlueZone supports the following SNA Communications Server Gateway options:

  • Microsoft Host Integration Server (formerly Microsoft SNA Server)
  • Microsoft SNA Server
    Configuring the Microsoft SNA Server (now called Microsoft Host Integration Server) connection consists of selecting a Logical Unit (LU) or LU Pool Name for BlueZone to use when initiating connections with the host system. The LU / Pool Names are listed and maintained on the SNA Server and are displayed by BlueZone in the SNA Server property page.
