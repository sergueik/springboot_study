Configuring the save options

The BlueZone Tab profiles are saved when the program is closed.

  1. In the BlueZone Tab toolbar, click the Settings icon.
    By default, the BlueZone Tab toolbar is located in the bottom right corner of the window.
  2. On the Options tab, select one of the Save on Shutdown options.
  3. To hide the Add Tab icon and the toolbar icons, select the Hide User Elements check box.
    When this check box is selected, you must manually edit the configuration to make any changes to the BlueZone Tab session.
  4. Click OK.
