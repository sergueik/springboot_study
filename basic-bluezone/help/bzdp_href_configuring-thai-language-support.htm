Configuring Thai language support

Starting with version 7.1, BlueZone has added Thai language support to BlueZone Mainframe and BlueZone iSeries emulators.

Note: Before configuring Thai language support in BlueZone, you must first enable a Thai keyboard input language in Windows. (For more information on changing the Windows language and keyboard layout, consult Microsoft Support.)

Launch a BlueZone IBM Mainframe 3270 Display session and complete the following steps to configure all settings. When configuration is complete, disconnect and re-connect the session to the host system.

Emulation settings

  1. From the BlueZone menu bar, click Session → Configure.
  2. Click the 3270 Emulation tab.
  3. In the Language (CCSID) list box, set the language to Thai (838).
    Note: If the Euro currency character is needed, then enable the Euro check box. The CCSID will change to Thai (1160).
  4. Press the Thai Options button.
  5. Set desired options, and click OK:
    Note:
    • Display in Unicode – Enable to display Thai characters as composed Unicode characters (default), or disable to display Thai characters in composite form. In composite form, all base and diacritic characters are displayed as separate characters.
    • Compose Characters while Typing – Enable to display and type Thai characters in the active 3270 field as composed Unicode characters, or disable to display and type Thai characters in composite form. In composed form, base and diacritic characters are combined and displayed as single Thai characters.
  6. Click OK to close the Session Configuration window.

Thai Key Mappings

  • Compose Toggle (Ctrl+M) – Toggles characters in the active 3270 field to and from composed and composite forms.
  • Input Language Thai (Ctrl+.) – Changes the keyboard input language to Thai for the active BlueZone session.
  • Input Language Latin (Ctrl+,) – Changes the keyboard input language to English for the active BlueZone session.

Display settings

  1. From the BlueZone menu bar, click Options → Display. The Font tab automatically displays.
  2. Click the Change button to open the Font window.
  3. Set the font to any monospaced fixed-width Unicode font that supports Thai script (for example, Courier Mono Thai).
  4. In the Script list box, select Thai. Click OK to close the Font window.
  5. Click OK to close the Display Options window.

Print Screen settings

  1. From the BlueZone menu bar, click File → Print Setup
  2. Select the Font tab
  3. Click the Change button to open the Font window.
  4. Set the font to any monospaced fixed-width Unicode font that supports Thai script (for example, Courier Mono Thai).
  5. In the Script list box, select Thai. Click OK to close the Font window.
  6. Enable the Print in Unicode option
  7. Click OK to close the Print Setup window

Optional Text Selection settings

When selecting text for Edit → Copy operations, BlueZone uses the Thai composite form of the text from the 3270 screen buffer. We recommend enabling the Use Colors to show Selected Text option (enabled by default), so that selected Thai characters display on the screen in composite form rather than composed form. To enable or disable the Use Colors to show Selected Text option:

  1. From the BlueZone menu bar, click Edit → Properties.
  2. Open the General tab
  3. Select Use Colors to show Selected Text. Click OK to close the Edit Properties window
