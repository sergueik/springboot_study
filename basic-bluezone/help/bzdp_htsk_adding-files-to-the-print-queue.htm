Adding files to the print queue

BlueZone has the ability to open text files from disk for printing. Perform the following steps to add a file to the Print Queue.

  1. On the BlueZone menu bar, click Action → Add File to Queue or click the Add File to Queue icon on the BlueZone toolbar.
    The Create Print Queue Job Entry dialog opens.
  2. Select the text file that you want to print and click Open.
    BlueZone creates a print job entry in the Print Queue for the file. The initial name of the print job is the file name of the selected file.

    The print job created takes on the print settings configured in BlueZone Print Setup.
