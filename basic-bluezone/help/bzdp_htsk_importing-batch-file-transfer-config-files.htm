Importing batch file transfer configuration files

You can import Batch File Transfers that have been previously saved.

  1. Click Transfer → Configure from the BlueZone menu bar.
  2. Click the Batch Transfers tab.
    The Batch Transfers dialog opens.
  3. Click the Import icon located on the Host File Transfer toolbar.
    A standard Windows File Open dialog displays.
  4. Locate the configuration file that you want to import, highlight the file, and click Open.
