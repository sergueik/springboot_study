Transferring files

Click Transfer → Configure from the BlueZone menu bar.
The Host File Transfer property sheet displays.
Important: In Kermit File Transfer, the sending and receiving of files is from the perspective of the host system. For example, sending a file means that the host is sending a file to your PC. Receiving a file means that the host is receiving a file from your PC.
  • Sending files to the host (host receive)
  • Receiving files from the host (host send)
