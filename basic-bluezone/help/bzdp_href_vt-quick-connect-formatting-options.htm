Quick Connect formatting options

In the Quick Connect window, you can type a new host address using the following formatting options.

Format Example
address 127.0.0.1
connection name (address:port) Solaris Server (myserver:23)
Protocol options

  • Telnet: Default connection.

  • SSH v2: Connects to the SSH daemon on the configured server.

    The default port is 22 unless a value is set for address:port. User ID and password settings are only enabled if you connect with SSH v2. If you have not specified these settings, you will be prompted to enter your user ID and password when you connect.
