LU functions

BlueZone scripts have the ability to send all host specific key sequences or commands to the host system. We refer to these host specific commands as LU Functions.

Each BlueZone emulator has it's own set of LU functions. That is because each host has it's own proprietary set of sequences and commands that are specific to that particular type of host.

For example, Enter Attention, Reset and Erase EOF are examples of IBM 3270 Mainframe commands.
Note: Script events and menu commands are the same for all emulators.

A list of all available LU functions for a specific BlueZone emulator can be viewed in the LU functions pane of the BlueZone Script Editor. Select the desired Mode (emulator) from the toolbar. All available LU functions for that emulator are displayed.
