Changing the window title

You can configure the title bar text in the BlueZone Tab window to use common variables or create a custom title bar.

  1. In the BlueZone Tab toolbar, click the Settings icon, and then click the Title Bar tab.
    By default, the BlueZone Tab toolbar is located in the bottom right corner of the window.
  2. To use the common variables, select one or more of the following check boxes and then type a character that separates the values in the Separator field. (The default separator is space hyphen space.)
    Check Box Description
    Profile Name (%1) Displays the profile name of the tab file. You must save the BlueZone Tab profile before the profile name displays in the title bar.
    Program Name (%2) Displays BlueZone Tab.
    Active Window Title (%3) Displays the title bar information for the active session that is set in the File Properties window on the Title Bar tab.
  3. To create a custom title bar:
    1. Select the Display Custom Title Bar check box.
    2. In the field, type the custom text. You can also use the %n variables.
  4. To display the selected tab’s session icon in the toolbar, select the Display Active Window Icon.
    If this check box is cleared, the BlueZone Tab program icon is displayed in the title bar.
  5. Click OK.
