License Server tab

The License Server tab is used to store the IP address of the BlueZone License Manager server. This is required when using a concurrent licensing scheme.
Note: The License Server tab will only appear if you are using a licensed copy of BlueZone. If you currently evaluating BlueZone this tab will not appear.
License Servers
Use this group to configure your BlueZone License Manager IP address:
  • Add Server: Place the IP address of the server or servers that are running the BlueZone License Manager in this filed and click Add.
    Note: If your BlueZone License Manager is using a Listening Port other than the default of 8421, you must add the configured port number to the end of the IP address, using a comma as a separator. Example: 63.75.199.234,80
    CAUTION:
    Do not use a colon ( : ) between the IP Address and the Port number. You must use a comma as shown above.
  • Server List: This will display the IP addresses of your BlueZone License Manager server (if any).
  • Use the Remove and Clear buttons as needed.
Group Information
This field is only used if you are using the Group feature of the BlueZone License Manager:
  • Group Name: Type the name of the Group in this field.
