What’s new in this release

This section summarizes the significant improvements or enhancements for BlueZone Display and Printer Version 7.1. Minor modifications to the text are not listed.

BZD-0701-UG-04 April 2017
  • Clicking the Command History button a second time will now close the Command History window in BlueZone 6530 display sessions.
  • Enhanced the Auto-Deselect After Copy function to work for drag and drop.
  • Added support for x11 forwarding in BlueZone VT and 6530 sessions.
  • Added a check box to control Active Telnet Negotiation in BlueZone VT sessions.
  • Added the option to treat leading nulls as spaces.
  • Enhanced the Edit → Copy function to remove tabs from clipboard text when using BIFF.
  • Added the Auto-Expand function.
  • Enhanced the customizable BlueZone toolbar.
  • Increased the maximum number of Hotspots supported.
