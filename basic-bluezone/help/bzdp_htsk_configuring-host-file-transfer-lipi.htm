Configuring the host file transfer

You must configure the following host file transfer options.

  1. Configure the transfer setup options.
  2. Optional: Configure the data format options.
  3. Optional: Build SQL queries.
  4. Optional: Add the host file transfer icon to the BlueZone toolbar.
  5. Set the file options.
  6. Add libraries to the Host Files pane.
  7. Remove libraries from the Host Files pane.
  8. Save the configurations.
  • Configuring the transfer setup options
  • Configuring the data format options
    You can specify the data format options of the transferred files.
  • Building SQL queries
    SQL queries are used when downloading one or more files to your PC. An SQL query allows you to select specific records, how they are sorted, and how they are grouped. You can enter the SQL query directly into the edit box or use the SQL Query Options dialog to create SQL queries.
  • Adding the transfer icon to the toolbar
    You can add the BlueZone Host File Transfer icon to the BlueZone toolbar.
  • Setting the file and tracing options
    You can save your host file transfer settings to a file, set program options, and configure tracing. BlueZone Host File Transfer has the same file save options as found in the BlueZone Display emulators.
  • Adding libraries to the host pane
    To add a library to the Host Transfer pane, the library must already exist on the host system.
