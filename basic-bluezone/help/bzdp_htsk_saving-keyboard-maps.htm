Saving keyboard maps

With BlueZone, it is possible to create a custom keyboard map file and save that file so you can share the keyboard map with others.

To export (save) a keyboard map file:
  1. Launch a BlueZone display session.
  2. From the BlueZone menu bar, click Options → Keyboard or click the Keyboard icon on the BlueZone toolbar.
    The Keyboard Options dialog displays.
  3. Make any desired keyboard map changes if you haven't already done so.
  4. In the lower left hand corner, click the Export Keyboard Options icon .
    A standard Windows file dialog opens.
  5. Type a name for the keyboard map file that you want to export (BlueZone automatically adds the correct file extension).
  6. Click Save.
    You have successfully exported your keyboard map to the BlueZone Config folder.
