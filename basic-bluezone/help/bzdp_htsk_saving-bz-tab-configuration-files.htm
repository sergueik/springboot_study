Saving BlueZone Tab profiles

BlueZone Tab profiles are saved when the program is shut down. You can configure BlueZone Tab to automatically save the profile on shut down. For more information, see Configuring the save options.
  1. Close the BlueZone Tab application.
  2. In the Close Program window, click Yes.
  3. If you have not named the profile, enter a name for the file, and click Save.
    If one of the BlueZone Display, Printer, or FTP sessions is configured to prompt for saving, you are prompted to save those sessions before BlueZone Tab closes.
