Mapping scripts to the keyboard

After a script has been created and tested, it can be mapped to a keyboard key to make it instantly accessible from the keyboard.

  1. From the BlueZone menu bar, click Options → Keyboard.
  2. From the Functions Group list, select Menu Hotkeys.
  3. From the Functions list, select Script → Play.
  4. Click New to create a new key mapping.
  5. Click the key on the keyboard bitmap that you want to execute the Script. Use the Control or Shift keys if necessary. The keys selected display in the Key Mappings field.
  6. Click OK to save and exit the window.
  7. From the BlueZone menu bar, click File → Save.
