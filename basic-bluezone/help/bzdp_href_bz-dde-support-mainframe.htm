BlueZone DDE support

BlueZone is a DDE server and uses DDE to communicate with the HLLAPI interface. BlueZone also uses Network DDE to allow communication across a network between a DDE application running on one system and BlueZone running on another. DDE calls supported in BlueZone are detailed in the BZDDE.H file supplied in the BlueZone CD image.

Note: The BZDDE.H file is located in the Docs folder in the BlueZone CD image.
