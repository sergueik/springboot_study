### Background

[Woodpecker CI](https://woodpecker-ci.org/docs/intro) is a lightweight, community-driven, container cluster based [CI](https://en.wikipedia.org/wiki/Continuous_integration)/[CD](https://en.wikipedia.org/wiki/Continuous_delivery) engine that functions like a self-hosted alternative to [GitHub Actions](https://docs.github.com/en/actions) or [Drone CI](https://docs.drone.io/) by [Harness](https://www.harness.io/) offering [local execution](https://woodpecker-ci.org/docs/usage/local-execution) anong other features. The Woodpecker actually performs deployment too. The Isolation is exclusive Docker images pulled dynamically for specific tasks, eliminating the need to pre-install fast expiring runtime tools like Node.js or Python on host infrastructure
